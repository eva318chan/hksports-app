Batch images（批量生圖）

用 Gemini Batch API 批量生成 AI 設計圖片。生圖前先睇清楚每篇嘅 prompt，改好先㩒 Generate。建議每批 10 篇左右；揀多過 10 篇會彈 warning，確認後照樣可以提交。生成要等一段時間（最長 24 小時），Check 唔係即刻有圖。批咗嘅圖先會上 R2 並連結返原文。

⚠️ 自動流程暫停（2026-11-14 江仔決定）：而家只做手動測試（揀文 → Generate → Check → 睇圖 → Approve），自動交 batch 同自動批准未接通，等測試滿意先開。
